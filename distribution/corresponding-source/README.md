# FolderSail library notices and corresponding source

FolderSail 1.0.1 includes the original runtime notices in `notices/`, mapped to exact dependency versions and selected assets by `runtime-notices.json`. These notices supplement the existing application `NOTICE.md`, `LICENSE-MIT`, `LICENSE-MPL`, and SQLite notices. Upstream copyrights and terms remain in force.

Public source and build instructions: https://foldersail.trieflow.com/source

The six exact source archives are available at https://github.com/hashfunction/filequay/releases/tag/native-sources-2026-09-12. `source-release-assets.json` records immutable upstream URLs, source revisions, archive sizes and SHA-256 values. `native-source-publication.json` records anonymous verification of every published byte. The release exporter independently downloads them again and verifies the current application archive against every Git blob of the exact build commit. Application source is available at `https://github.com/hashfunction/filequay/archive/<exact-build-commit>.tar.gz`; the exported release receipt supplies that commit and archive hash.

`prepare_source.py` reproduces the two media-free archives from their exact original archives. `source-derivation.json` records every retained and omitted path and SHA-256. This filtering changes no library implementation or build input. The original upstream archive URLs and hashes remain recorded. Run `python prepare_source.py --help` for its arguments. Two independent local derivations produced identical archives; that is source-archive verification, not a claim that the library binaries were rebuilt.

## Building and replacing libraries

Use the exact source revisions above and the original included build instructions. Use the application's pinned .NET SDK from `global.json` for managed builds and the Windows x64 compiler toolchain for native builds.

For 7-Zip, open an x64 Visual Studio developer command prompt (`vcvars64.bat`), enter `CPP/7zip/Bundles/Format7zF`, and run `nmake`. The upstream makefile builds `7z.dll`; use that output as `7z64.dll` for this x64 application. The original `DOC/readme.txt` documents supported Visual Studio and assembler prerequisites.

For SevenZipSharp, run `dotnet build SevenZip/SevenZip.csproj -c Release -p:Version=1.0.3`. For TagLibSharp, run `dotnet build src/TaglibSharp/TaglibSharp.csproj -c Release -p:LibTargetFrameworks=netstandard2.0 -p:GeneratePackageOnBuild=false`. The original source includes its signing key and version properties; the library build does not need the excluded test media. For UTF.Unknown, build its original `src/UTF-unknown.csproj` for net8.0 with release version 2.6.0; the published file version is 2.0.725.0 and assembly version is 2.0.0.0. The original source includes the required key and build configuration.

For libgit2, place the contents of the exact libgit2 source archive in the wrapper's `libgit2/` submodule directory. Run the wrapper's `build.libgit2.ps1 -x64` using its documented CMake/Visual Studio prerequisites. Its original Windows settings use Schannel HTTPS, disable SSH/tests/CLI, and name the output `git2-a418d9d`. The wrapper places the result under `nuget.package/runtimes/win-x64/native`.

These libraries are separate dynamically loaded files. You may modify them and debug those modifications, including reverse engineering needed to debug modifications to LGPL components. Build the full application from its current corresponding source, or unpack an unsigned MSIX using the Windows SDK, replace the relevant library, and repack/sign your own local test copy. Use an identity and certificate you control for that modified copy. Windows package integrity protects an installed Store package, so replace libraries in an unpacked or rebuilt copy. Application source and build scripts are included; the release qualification hashes certify the distributed original and do not prohibit rebuilding modified versions. No actual Windows replacement demonstration or reproducible binary build is claimed by the source publication record.

## Microsoft components and provenance limits

The selected .NET 10.0.12 runtime and Windows Desktop runtime retain their original MIT licenses and full third-party notices. Windows App SDK component licenses and notices, WinUI, WebView2, and the stable Windows SDK .NET projection 10.0.26100.70 terms are retained at their exact package versions. The projection release and applicable redistribution terms are documented in the application's `distribution/sdk-audit` source record. Framework installation comes from the package's declared Microsoft dependency; the installer records the actual dependency identity and bytes.

Win2D 1.3.2's original NuGet package, `Win2d.githash.txt`, and both DLLs identify source revision `feefabe2d8ef80025030c1dd7c9d3d71e2462cd3`. The native DLL matches the observed application payload exactly. That revision is not available from the public Microsoft/Win2D commit endpoint. The NuGet package identifies Microsoft's original Win2D EULA URL, which now redirects to generic documentation. Its unchanged windows-1252 original HTML is retained under `notices/native-Microsoft.Win2D`: independent 2021 and 2025 raw archived captures of that Microsoft URL are byte-identical and match the archive CDX content digest. Section 2 permits object-code redistribution subject to the full requirements and restrictions. `FolderSail-License-Terms.txt` contains a scoped downstream agreement and every original English/French term, and is prepared for the Store license field. A separately observed Microsoft repository MIT notice remains attributed to its own immutable revision; it is not presented as the license or source used to build this NuGet binary. Exact package/DLL hashes, archive provenance and downstream terms hashes are in `runtime-notices.json`. The build-source revision remains unavailable; no replacement commit is invented.

SQLite's existing package lock and public-domain/Apache notices remain under `Licenses/SQLite`. The exact native source ID is tested by executing the shipped native bytes; the vendor compiler/build recipe is not claimed to have been reproduced.
