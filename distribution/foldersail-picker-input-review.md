## Narrow correction

- Keep the original filename Value action. Before Save, read its actual current
  ValuePattern, retain expected/value/read-only/ownership facts with a bounded
  value and explicit truncation flag, and require exact selected CSV text.
  Changed identity, ownership, read-only state or differing text fails before
  any Save input. No normalization or retry conceals a different destination.
- Only native Save (`1` / `Save`) and overwrite Yes (`6` / `Yes`) use focused
  Space. Their exact visible/enabled/focusable Button identity and PID/native
  HWND are checked, normal UIA SetFocus runs once, and the same live identity,
  focus and original ownership predicates are checked again. An actual error
  dialog is neither dismissed nor treated as a confirmation.
- The existing compiled, IL-only qualification adapter sends one Space down/up
  pair. Immediately before SendInput, it checks retained processes,
  foreground/owner chain, the exact child HWND's PID/root/visibility/enabled
  state, and actual GUI-thread active/focused HWNDs. Failed focus queries and
  drift prevent input; a partial SendInput fails without replay. Focus failures
  retain the bounded expected/observed native handles in their exception.
- GetGUIThreadInfo is generated by the same pinned CsWin32 0.3.298 toolchain.
  It is the single explicitly allowed qualification-only observation API in
  the existing exact call/input subset check. Customer NativeMethods.txt is
  unchanged. [Microsoft documents](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getfocus)
  this API for inspecting another GUI thread's focus. No attached input queue,
  private framework mutation, alternate provider or synchronous button-message
  fallback is added. Generic Chord and app Invoke behavior are preserved.
- The existing native/app replacement decisions, selected-path confirmation,
  original CSV proof, complete CSV oracle/recovery, history clearing,
  close/disappearance policy and cleanup remain required. The two new replay
  tests are checked invocations in the normal Windows qualification script.
